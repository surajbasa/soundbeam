SoundBeam

Transfer a small file from one device to another using speaker-to-microphone audio tones. No internet connection is used for the transfer.

📤 Send a file

Choose a small file. This prototype converts each 4-bit group into one of 16 audio tones.

Choose a file to begin.

Keep the sender volume moderate and the devices close together. The audio will be audible.

📥 Receive a file

Start listening on this device first, then press Play on the sender device.

Waiting for microphone permission.

Use Chrome or Edge over HTTPS (or localhost). Allow microphone access when prompted.

Prototype limits: This is a proof of concept, not a polished high-speed modem. Audio transfer is slow and sensitive to room noise, device audio processing, and timing. Start with files under 1 KB. For private or important files, use a trusted transfer method instead.

How to test with two devices

  1. Publish this page on GitHub Pages (HTTPS), or run it locally on both devices.
  2. On the receiving phone, tap Start microphone and allow access.
  3. On the sending phone, choose a small file and tap Play transfer tones.
  4. Keep the speaker near the receiving microphone. If it fails, try a quieter room and a smaller file.

The receiver looks for a sync sequence, then decodes the file name, file length, and bytes. A checksum detects corrupted transfers.
